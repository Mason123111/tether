01 / 도입 효과

현금을 관리할 일이
사라집니다.

입금 확인은 시스템이 자동으로 처리하고, 귀사는 지금처럼 승인만 하면 됩니다.

현금 관리가 필요 없습니다

통장 관리와 현금 처리 업무가 없어집니다.

기존 운영 방식 그대로

입금, 집금, 송금 내역이 시스템과 블록체인에 함께 남아 언제든 확인할 수 있습니다.

05 / 자금 흐름

테더는 네 단계로
이동합니다.

유저가 보낸 테더는 유저별 지갑으로 들어와 집금 지갑에 모이고, 귀사가 지정한 외부 지갑으로 나갑니다.

유저 개인 지갑

유저가 자신의 지갑에서 직접 보냅니다.

유저별 지갑

유저마다 전용 주소가 하나씩 발급됩니다.

집금 지갑

유저 지갑의 테더를 모읍니다. 여러 개를 두고 유저별로 연결할 수 있습니다.

외부 지갑

상위관리자 이상이 미리 등록한 주소로만 보냅니다.

자금을 단계별로 나눠 두어,
문제가 생겨도 피해가 가장 바깥쪽
유저 지갑에서 멈추도록 설계했습니다.

유저 지갑입금 후 잠시 머무름
집금 지갑주기적으로 모음

08 / 보안

돈이 나가는 길은
하나로 정해져 있습니다.

미리 등록한 주소, 정해진 절차, 남는 기록.

KEY

개인키 내부 보관

개인키와 시드는 시스템 내부에만 보관되며 관리자 화면에 노출되지 않습니다.

LAYER

단계별 자금 분리

유저 지갑, 집금 지갑, 외부 지갑으로 나눠 보관해 피해 범위를 좁힙니다.

ADDRESS

등록 주소로만 출금

외부 송금은 상위관리자 이상이 미리 등록한 주소로만 가능합니다.

PROCESS

송금 확인 절차

외부 송금은 요청, 확인, 2차 인증을 거쳐야 실행됩니다.

LOG

모든 활동 기록

관리자의 조회, 집금, 송금, 설정 변경이 모두 기록됩니다.

ACCESS

접속 제한

허용된 장소(IP)에서만 관리자 화면에 접속할 수 있습니다.
